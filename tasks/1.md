# Task 1 — Sanitization Standards and Safety Model

## Objective

Define OSCP’s standards-based model for secure media sanitization, including when the application must refuse to claim success.

## Scope

- Use NIST SP 800-88 Rev. 2 as the primary reference.
- Map HDD, SSD, NVMe, USB flash, encrypted, unsupported, and failing-device cases.
- Define the differences between Clear, Purge, Cryptographic Erase, and Destruction.
- Define verification requirements and uncertain outcomes.

## Deliverables

- A sanitization decision matrix.
- A list of required device capability fields.
- Result states: `Completed`, `Failed`, `Interrupted`, and `VerificationUncertain`.
- User-facing warnings that avoid promising unrecoverability when the device cannot support it.
- Updates to `docs/security-and-safety.md` and `docs/architecture.md`.

## Acceptance criteria

- No generic wipe method is selected solely from the device label.
- SSD/NVMe methods differ from HDD methods.
- Unsupported or unverifiable devices produce a refusal or destruction recommendation.
- Every successful result includes the selected method and verification evidence.
- Standards references identify NIST SP 800-88 Rev. 2, not Rev. 1.

## Dependencies

- Device capability model from Task 2.
- Audit schema from Task 4.
